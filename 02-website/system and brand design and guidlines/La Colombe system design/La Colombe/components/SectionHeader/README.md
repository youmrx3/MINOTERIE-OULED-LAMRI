Overline, title, gold rule and intro that open each section.

**Consumer provides:** Provide overline text, a title (`h2`; `h1` on a page head) and one intro paragraph.

**Use:** Left aligned by default, `lc-sh--center` for centered. The overline is uppercase in French and plain in Arabic.

**Don't:** Don't set the overline in `primary-500` on light surfaces: use `accent-text`.
