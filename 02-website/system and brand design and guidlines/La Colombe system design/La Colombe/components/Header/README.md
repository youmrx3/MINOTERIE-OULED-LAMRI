Site header with logo, navigation, language switcher and Call button; below 1024px it collapses to a menu button and a drawer.

**Consumer provides:** Provide the seven navigation labels, the current page (`aria-current="page"`), the phone number and the language switcher. The drawer carries the Call and WhatsApp buttons.

**Use:** Desktop shows navigation inline. Mobile shows logo, switcher and a 44px menu button; the drawer (`.lc-drawer`) opens under the bar.

**Don't:** Don't hide Call behind the drawer on desktop. Don't animate the drawer beyond a fade.
