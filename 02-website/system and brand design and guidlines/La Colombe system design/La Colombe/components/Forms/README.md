Contact form controls: text, phone, select, textarea, helper and error text, success banner and a submit button with a loading state.

**Consumer provides:** Provide a visible `<label>` for each control, `aria-describedby` for helper or error text and `aria-invalid` on errors.

**Use:** Controls are 48px high with a 1.5px `border-strong` border. Phone shows `+213` on the left in both directions. Errors are an icon plus text in `error`.

**Don't:** Don't use placeholder text as a label, don't show a spinner.
