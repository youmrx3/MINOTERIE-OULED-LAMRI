Underlined text links plus inline phone, e-mail and arrow links.

**Consumer provides:** Provide the link text and `href`. Phone and e-mail values go inside `.lc-ltr` so they stay left-to-right in Arabic.

**Use:** Use `lc-link` for stand-alone links (44px target), `lc-link--inline` inside a sentence, `lc-link--arrow` for "see more" with the directional arrow.

**Don't:** Don't remove the underline, don't color links gold on light surfaces.
