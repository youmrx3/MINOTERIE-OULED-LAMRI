The La Colombe icon set: 24px grid, 1.5px line, round caps and joins, no fill.

Every SVG is single-ink in earth brown `#4A3B2A` (`secondary-700`), because an `<img>` cannot inherit `currentColor`. To recolor, use the inline sprite in the Icons component or edit the `stroke` value. `chevron-rtl.svg` and `arrow-rtl.svg` are the mirrored versions for right-to-left pages; all other icons never mirror.
