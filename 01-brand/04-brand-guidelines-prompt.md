# Brand guidelines prompt — LA COLOMBE

Run this **after** the design system (`03-design-system-prompt.md`), in the same Claude Design project so it can read the tokens. Attach the client's logo again if you start a new project.

The logo already exists, so this prompt does not create a logo. It documents how the brand is used.

---

## Main prompt

```
Create the brand guidelines for "LA COLOMBE", the brand of SARL Minoterie
Ouled Lamri, a flour mill in Bordj Bou Arréridj, Algeria. The attached file is
the official logo: use it exactly as provided. Do not redraw, recolor, outline
or modify it. Use the colors and typography already defined in the design
system of this project.

FORMAT
A landscape guideline document of 14 to 16 pages, one topic per page, clean
cream background, brown text, gold accents, generous white space. Every page
is bilingual where text appears: French first, Arabic below or beside it.

PAGES
1. Cover: logo, "Brand guidelines", year.
2. Brand essence: who the brand is, what it stands for, three values, one
   positioning sentence in French and in Arabic. Base it only on facts given
   here: flour mill, Bordj Bou Arréridj, brand name LA COLOMBE (the dove),
   serving bakers, pastry makers, wholesalers and households. Do not invent
   history, dates, certifications or numbers.
3. Logo: primary version, stacked version if the file has one, symbol alone.
4. Clear space and minimum size: define the clear space unit from a part of
   the logo itself, show it around the logo, and give minimum sizes for print
   (mm) and screen (px).
5. Logo on backgrounds: on cream, on white, on brown, on gold, on a photo
   (with a darkened overlay). Show which version is used where.
6. Logo misuse: stretching, rotating, recoloring, adding effects, placing on
   low contrast, adding a shadow, changing the proportions. Six examples.
7. Color: the palette with HEX, RGB, CMYK, proportions of use (for example
   60 / 30 / 10) and approved pairings with contrast ratios.
8. Typography: Latin and Arabic families, hierarchy example, and rules for
   mixed French/Arabic layouts.
9. Imagery direction: real photography of the mill, sacks, grain, flour and
   people at work. Warm natural light, honest and unstaged, flour texture
   close-ups, no stock-looking smiles, no heavy filters. Describe the shot
   list as text boxes with neutral gray frames, no generated photos.
10. Image placeholder: the logo as a still watermark on a cream surface,
    used until real photos are available. Show the ratios 4:3, 16:9, 1:1.
11. Iconography and graphic elements: the icon style from the design system,
    one repeating pattern derived from the logo or a wheat motif, and where
    the pattern may be used.
12. Tone of voice: five principles, with a do and don't sentence for each,
    written in French and in Arabic. Plain, warm, precise, no exaggeration.
13. Print applications: flour bag front (flat mockup), business card, letterhead.
14. Digital applications: website header, WhatsApp profile picture, Facebook
    cover, Instagram post template (square and story).
15. Physical applications: stamp or seal, delivery vehicle side panel, shop
    or factory sign (flat mockups, no photo realism).
16. Quick reference: one summary page with logo, colors, fonts, and ten rules.

RULES
- No gradients, no shadows, no glossy effects, no emoji, no invented claims.
- Arabic text must be correct, natural and properly shaped. Use right-to-left
  direction for Arabic blocks.
- Phone and email stay left-to-right inside Arabic text.
- Keep the document consistent with the website design system: same colors,
  same type, same placeholder rule.
```

## Follow-up prompts

**Arabic proofreading**
```
List every Arabic sentence in the document and check spelling, shaping,
diacritics and naturalness for an Algerian audience. Correct anything that
reads like a literal translation.
```

**Pocket version for the client**
```
Create a 4-page summary of these guidelines for a non-designer: the logo and
how to place it, the colors, the fonts, and five things never to do.
```

**Social media kit**
```
Create a social kit: profile picture, Facebook cover, Instagram feed template
with three layout variants (announcement, product, message), and a story
template. Use only brand colors and the logo. Leave image areas as the
placeholder.
```
